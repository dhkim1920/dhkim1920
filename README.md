# Data Engineer Profile
데이터 엔지니어링을 기반으로 시스템 구축 및 데이터 자동화를 수행해 왔습니다. Spark, Hadoop, Kafka, Airflow 등을 사용해 데이터를 처리한 경험이 있으며, 데이터 처리뿐 아니라 Docker 및 GitLab 기반 CI/CD 환경 구성 등 운영 자동화 경험도 보유하고 있습니다. 데이터 엔지니어로서 데이터 흐름을 최적화하고 장애를 신속히 진단하여 안정적이고 신뢰할 수 있는 플랫폼을 구축하는 것을 목표로 합니다.

## Core Competencies
- 분산 데이터 처리 아키텍처 설계 및 운영
- 배치/스트리밍 파이프라인 개발 및 성능 최적화
- 데이터 품질 관리, 모니터링, 장애 대응 체계 구축
- CI/CD 기반 데이터 플랫폼 운영 자동화
